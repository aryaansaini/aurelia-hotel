# Aurelia Hotel — React single-page website

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite (normally http://localhost:5173).

## Where to edit

- `src/data/hotel.js`: hotel address, phone, email, room cards, prices and photo IDs.
- `src/components/Header.jsx`: navigation and mobile menu.
- `src/components/BookingForm.jsx`: check-in, check-out and guest form (demo only).
- `src/components/Footer.jsx`: contact details and footer links.
- `src/App.jsx`: page sections, content and layout.
- `src/style.css`: colors, typography, spacing and mobile styles.
- `index.html`: page title and SEO description.

## Important

- `hello@aureliahotel.com` is a proposed email address, **not a verified working mailbox**. Replace it with an email you own before publishing.
- Room rates, amenities, statistics and photos are placeholders.
- Booking availability is not connected to a backend; submitting the form only displays a demo message.
- Photos load from Unsplash and require internet access.
